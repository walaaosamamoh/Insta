# Instagram Clone

A responsive Instagram-inspired social media application built with **Vue.js**, **Pinia**, and local mock data. The project focuses on reusable components, state management, authentication flow, and responsive UI development.

## 🚀 Live Demo

[Instagram Clone](https://insta-phi-jet.vercel.app/)

## ✨ Features

* User authentication with login flow
* Instagram-style feed and posts
* User profiles
* Stories section
* Post interactions
* Centralized state management with Pinia
* Reusable Vue components
* Responsive design for desktop and mobile
* Local mock data for application content

## 🛠️ Technologies

* Vue.js
* JavaScript
* Pinia
* Vue Router
* HTML5
* CSS3
* Responsive Design
